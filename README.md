# 拾鲜生 · 2026 标配套餐产品展示页

静态营销展示页：12 个产品系列、75 款商品（名称 / 规格 / 图片 / 零售价 / 配送区域 / 上市周期）。

## 下载后如何打开

1. 下载本仓库（Code → Download ZIP，或 `git clone`）；
2. 解压后双击打开 **`index.html`** 即可；
3. 无需服务器、无需联网加载依赖——所有图片已内嵌进 HTML（base64 自包含），不会缺图。

> 页面内交互：顶栏分类导航（滚动自动高亮）、产品/食材搜索、点击图片放大、咨询二维码弹层、返回顶部。桌面 / 移动端均适配。

## 文件清单

| 文件 | 说明 |

- 商品数据源：《2026 拾鲜生标配套餐报价》xlsx（12 个工作表，75 条记录，已逐项核对一致）；
- 价格为零售价（人民币/盒），内部渠道价未展示；
